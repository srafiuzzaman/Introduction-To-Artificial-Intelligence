# Introduction to Artificial Intelligence

This repository contains individual projects and problem-solving exercises developed as part of an Introduction to 
Artificial Intelligence course. Each folder includes a separate AI problem, its implementation, and documentation.

## Projects

### [15-Puzzle Solver](./15-Puzzle-Problem/)

An implementation of the classic 15-puzzle using artificial intelligence search
algorithms and heuristic strategies.

**Concepts:** State-Space Search, Heuristics, Search Algorithms

---

### [Sudoku Constraint Satisfaction Solver](./Sudoku-CSP/)

A Sudoku-solving application that models the puzzle as a Constraint Satisfaction
Problem using backtracking, forward checking, and related AI techniques.

**Concepts:** Constraint Satisfaction Problems, Backtracking, Forward Checking

---

### [Decision Tree Classifier from Scratch](./Decision-Tree-Classifier-from-Scratch/)

A categorical decision-tree classifier implemented from scratch in Python. The
project compares Random, Least-Values, Most-Values, Gini Index, and Information
Gain as attribute-selection strategies.

A Tkinter interface allows users to compare generated trees, predictions, and
classification accuracy.

**Technologies:** Python, Pandas, Tkinter, Pillow  
**Concepts:** Decision Trees, Entropy, Information Gain, Gini Index, Classification
