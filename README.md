# Introduction to Artificial Intelligence

This repository contains individual projects and problem-solving exercises developed as part of an Introduction to 
Artificial Intelligence course. Each folder includes a separate AI problem, its implementation, and documentation.

## Contents
- 15-Puzzle Problem
  - A classic sliding puzzle implementation using AI search algorithms.
  - The project demonstrates how heuristics and search strategies can be applied to efficiently solve a 15-tile puzzle.

- Sudoku as a Constraint Satisfaction Problem
  - This project approaches Sudoku solving using Constraint Satisfaction Problem (CSP) techniques. 
  - It explores backtracking, forward checking, and other AI strategies to solve Sudoku puzzles efficiently.
